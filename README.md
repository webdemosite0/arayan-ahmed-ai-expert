# Arayan Ahmed — AI Expert

Premium personal portfolio for Arayan Ahmed, an AI-focused builder and creative technologist.

## What is included

- High-end navy / champagne-gold visual system
- Editorial typography with Instrument Serif + DM Sans + DM Mono
- Responsive one-page portfolio
- Expertise / capabilities section
- Trove AI featured product section
- Dedicated certificate gallery
- Full-screen certificate viewer
- Supplied credential designs presented as web-native SVG artwork
- Smooth hover states, ambient orbital visual and glass navigation
- Mobile-first responsive behavior

## Credentials

The portfolio presents the two supplied certificate designs:

- Trove AI — Artificial Intelligence Expertise Award
- ARTiBA — Certificate of AI Expertise

Certificate artwork is stored in `certificates/` and loaded directly by the site.

## Run

This is a static site. Open `index.html` directly or deploy the repository to GitHub Pages, Vercel, Netlify, or any static host.
